# AHT Decision-Support Framework

Repository accompanying the manuscript:
'A Conceptual Decision-Support Framework for Structured Assessment of Suspected Abusive Head Trauma'

## Files
- framework.py
- requirements.txt
- parameters.csv
- input/example_case.csv

## Installation
pip install -r requirements.txt

## Run
python framework.py

The script generates all figures and CSV files automatically.

Research use only. This is a conceptual decision-support framework, not a validated clinical prediction model.
